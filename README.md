# נוסחאות התלמוד — אנדרואיד

1. צרו ריפו **פרטי** והעלו אליו את כל התוכן (כולל `.github` ו-`signing`).
2. Actions ← Build Android APK ← Run workflow.
3. הורידו את `TalmudFormulas-apk` והתקינו.

- מאגר: בהפעלה ראשונה בוחרים את `talmud.db` מהמכשיר; אחר כך הכול אופליין. החלפה: הגדרות ← מאגר נתונים.
- חתימה: התיקייה `signing` מכילה את מפתח החתימה הקבוע. **אל תפרסמו אותה ואל תהפכו את הריפו לציבורי.** שמרו לעצמכם עותק שלה — בלעדיה אי אפשר לעדכן.
